# Ground truth

`h00.json` … `h09.json` hold one document per target and `assets.csv` holds every item as one row for spreadsheet
scoring. Both are generated by `tools/build_ground_truth.py` from the `# GT:<id>[/<role>]` markers in `targets/`
and validated at run time by `tools/runtime_witness.py`. Do not edit them by hand; edit the target or the
specification in the builder and re-run it.

## Items

| Field | Meaning |
|---|---|
| `id` | Stable identifier, e.g. `H4-U1-C`. The same string appears in the marker comment. |
| `status` | `active`, `registry` (H6: present in code, not selected by the shipped configuration), `unreachable`, `dead-branch`, `unresolved` (identity not determinable statically) or `decoy` (looks like cryptography, is not). |
| `runtime` | `executed`, `conditional` (depends on an environment variable or argument), `not-executed` or `n/a`. |
| `asset` | `name`, `family`, `primitive` (CycloneDX 1.6 vocabulary), the primary parameter (`key_bits`, `parameter_set`, `curve` or `output_bits`), `mode`, `padding`, `hash`, `quantum` (`shor-vulnerable`, `quantum-resistant`, `classically-broken`, `short-output`, `unknown`), `nist_qsl`, `classical_bits`, `standard`, `usage`. |
| `verdicts` | Verdict under each reference policy in `policies/reference_policies.yaml`. For the classical half of a hybrid the partner is taken into account; this is the only place where QR-STRICT and QR-HYBRID differ. |
| `locations` | `{file, line, role}` relative to the target folder. |
| per-hypothesis | `technique`/`visibility` (H1), `indirection` (H2), `visibility` (H3), `construction` (H4), `naming` (H5), `source` (H6), `track`/`depth`/`requires_propagation` (H7), `ideal_confidence`/`evidence` (H9). |

`units` (H4, H5, H8) group the items of one function and carry the function-level verdict: the most severe member
verdict (non-compliant > deprecated > unknown > compliant). `pairs` (H5) list the misleading/neutral twins.

Location roles: `use` (default), `keygen`, `op`, `def` (a declaration or template that carries the identity), `src`
(the literal that fixes a parameter), `padding`, `cfg` (a configuration-file line), `registry`, `vendored`, `decoy`,
and `anchor`. **`anchor` lines are runtime witnesses for code generated from strings; exclude them from scoring.**

## Recommended scoring

1. **Normalise findings.** CycloneDX 1.6 (CBOMKit, cdxgen): `components[type=cryptographic-asset]` with
   `evidence.occurrences[{location, line}]` (cdxgen may also attach call-stack frames). IBM CBOM 1.4
   (cryptobom-forge): `cryptoProperties.detectionContext[{filePath, lineNumbers}]` and `algorithmProperties.variant`.
2. **Match** a finding to an item when the path ends with the item's `file` and the line is within ±1 of a
   non-anchor location (or that location falls inside the finding's line range).
3. **Grade identity:** L0 not found; L1 family correct; L2 plus the primary parameter; L3 plus mode, padding or
   hash. A matched finding with the wrong family is a misidentification. Sub-component findings at an item's
   location (the SHA-256 inside RSA-PSS or HKDF, the curve inside ECDSA) are *decomposed*, not false positives.
4. **Decoys and leftovers.** Any finding on a decoy line is a false positive. H6 registry items are reported as
   over-approximation. Findings that match nothing are *unattributed* and are reviewed by hand.
5. **Condition on H0.** Report raw recall, and conditional recall over items whose library and family the tool
   detected at L1 or better in `h00`. Check every target's `*-PROBE` item first: a missed probe means the scan
   itself failed.
6. **Per hypothesis:** H1/H2/H3 by technique, indirection or library; H4/H5/H8 verdict agreement per unit and
   policy (aggregate per-component results with the same worst-of rule); H5 misleading-minus-neutral difference
   per pair plus decoy false positives; H6 per configuration source, including whether evidence points at the
   configuration file; H7 deepest depth reached at L1 and at L2 per track; H9 presence of confidence values and
   rank correlation (Kendall τ or Spearman ρ) with `ideal_confidence`.
