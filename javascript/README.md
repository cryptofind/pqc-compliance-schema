# JavaScript PQC benchmark cases

These targets are JavaScript counterparts to the Python H1-H9 cases. They keep
the same benchmark questions and expected algorithms while expressing each
technique with JavaScript and Node.js idioms. The H7 call-depth target is
generated by `tools/gen_h07.mjs`.

The targets are for static scanning. The benchmark does not run them or install
their dependencies. Some algorithms, particularly post-quantum algorithms and
third-party-library examples, are represented by API names or calls that may
require a supporting runtime/library to execute.

These are translated equivalents, not byte-for-byte ports or a controlled
language-only experiment. JavaScript idioms and cdxgen's language-specific
analysis affect visibility, so differences from the Python results cannot be
attributed to language alone.

Run cdxgen and score the nine targets with:

```powershell
python .\results\cdxgen\javascript\run_cdxgen_benchmark.py --write-manifest
python .\results\cdxgen\javascript\run_cdxgen_benchmark.py
```

Each run is saved in a new UTC-timestamped folder under
`results/cdxgen/javascript/runs/`. Existing results are not overwritten.
